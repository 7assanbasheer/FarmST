# 🌾 نظام إدارة ومحاسبة المزرعة المتكامل (Farm Management & Accounting System)

نظام سحابي متكامل لإدارة عمليات الإنتاج الزراعي، الحصاد اليومي، المخزون، المبيعات وإصدار الفواتير، المصاريف والمدخلات، مع محرك متقدم لاحتساب تكلفة الوحدة المنتجة وتقارير الأرباح والخسائر الشهرية (P&L).

قاعدة البيانات مبنية ومربوطة سحابياً بنسبة 100% مع **Google Cloud Firebase (Firestore)**.

---

## 🚀 الميزات الرئيسية

1. **🌿 رصيد المخزون للمحاصيل**:
   - عرض فوري ومباشر لرصيد المخزون لكل محصول في المزرعة.
   - إمكانية البحث السريع باسم المحصول أو تصنيفه.
   - أزرار سريعة للحصاد والبيع من بطاقة المحصول مباشرة.

2. **📋 سجل الحصاد والقطاف اليومي**:
   - توثيق الكميات المحصودة، الدرجة (نخب أول، نخب ثانٍ، تجاري)، موقع البيت المحمي/الحقل، وتاريخ الحصاد.
   - زيادة رصيد المخزون في السحابة فورياً وبشكل تلقائي.

3. **🛒 المبيعات وفواتير البيع**:
   - إصدار فواتير بيع متعددة الأصناف مع خصم آلي وفوري للكميات من رصيد المخزون.
   - دعم حالات الدفع: نقداً (كاش)، تحويل بنكي، أو آجل (ديون عملاء).
   - إمكانية استعراض وطباعة الفاتورة بتصميم رسمي وأنيق مع شعار المزرعة.
   - إمكانية إلغاء الفاتورة واسترجاع الكميات للمخزون آلياً.

4. **💰 المصاريف والمدخلات**:
   - تسجيل كافة المصاريف والتكاليف التشغيلية.
   - تتضمن خيار **أخرى (مصروفات متنوعة)** لأي مصروفات طارئة أو غير مدرجة.
   - إمكانية تخصيص المصروف لمحصول معين (مثل كراتين خيار أو سماد طماطم) أو اعتباره مصروفاً عاماً للمزرعة (مثل الديزل أو وايت الماء).

5. **📊 الأرباح والخسائر والتقرير الشهري (Monthly P&L & Crop Economics)**:
   - حساب إجمالي الإيرادات، إجمالي المصاريف، وصافي الربح/الخسارة عن أي شهر يتم اختياره.
   - **تحليل تكاليف وربحية كل محصول على حدة**:
     - حساب تكلفة إنتاج الوحدة الواحدة (Unit Cost = المصاريف المباشرة + نصيب المحصول من التكاليف العامة مقسوماً على كمية الحصاد).
     - مقارنة متوسط سعر البيع بتكلفة الإنتاج لمعرفة هامش ربحية المحصول بدقة.
     - طباعة التقرير الشهري أو حفظه كـ PDF بنقرة زر.

6. **👛 المحافظ والعهد النقدية وتأمين الدخول (محمد، علي، حسين)**:
   - شاشة تسجيل دخول مخصصة في بداية الدخول مع إمكانية الدخول السريع بنقرة زر.
   - **بيانات الدخول الافتراضية**:
     | المستخدم | اسم المستخدم | كلمة المرور |
     | :--- | :--- | :--- |
     | **محمد** | `محمد` أو `mohammed` | `123` |
     | **علي** | `علي` أو `ali` | `123` |
     | **حسين** | `حسين` أو `hussein` | `123` |
   - تخصيص محفظة نقدية وكاش لكل مستخدم لمعرفة الكاش مع من بالضبط.
   - نظام تسليم عهدة مع **طلب قبض معلق**:
     - يرسل المسلِّم طلب تحويل كاش بمبلغ وسبب العهدة.
     - يتلقى المستلِم إشعاراً فورياً بطلب القبض.
     - بالضغط على **"تأكيد الاستلام"**، يتم خصم الكاش من المسلّم وإضافته للمستلم فورياً.
   - زر لتسجيل الخروج بأي وقت مع حفظ الجلسة على المتصفح.

---

## 🛠️ كيفية تشغيل النظام

1. تأكد من وجود ملف الاعتماد السحابي `serviceAccountKey.json` في مجلد المشروع الرئيسي.
2. تشغيل الخادم بالأمر:
   ```bash
   node src/server.js
   ```
3. افتح المتصفح على الرابط:
   [http://localhost:5000](http://localhost:5000)
